# ProyectoEventos

Este es un proyecto creado para ir creando una pagina web paso a paso en clase.


# Tipos de eventos

---
## 1-Concierto

## 2-Carrera

## 3-Concurso Pesca

## 4-Festival gastronomico(FoodTruck)

## 5-Torneo de Videojuegos

## 6-Concierto(Tributo)
---
# Cada uno de los diferentes eventos esta compuesto por los siguientes campos

id-numero id

Nombre-Nombre del evento

Locaclizacion-En este campo se guarda donde se realiza el evento

Aforo- Numero de personas que pueden asistir

FIni-Fecha en la que comienza el evento

FFin-Fecha en la que finaliza el evento
